# NYC-Taxi-demand---supply-Allocation-simulation-framework-
ระบบขนส่งสาธารณะด้วยรถแท็กซี่สีเหลือง (Yellow Taxi) ในนครนิวยอร์ก (NYC) เผชิญกับปัญหาเชิงโครงสร้างที่สำคัญคือ ความไม่สมดุลระหว่างความต้องการใช้บริการของผู้โดยสารและปริมาณรถแท็กซี่ที่พร้อมให้บริการในมิติของพื้นที่และช่วงเวลาส่งผลให้เกิดภาวะแท็กซี่ขาดแคลนในบางเขต แต่เขตข้างเคียงกลับมีรถแท็กซี่จอดว่างหรือขับวนรอผู้โดยสารอย่างเปล่าประโยชน์
